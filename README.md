# 🃏 斗地主 · Doudizhu

> 零依赖 · 纯静态 · 打开即玩的经典斗地主 Web 游戏

一个用原生 HTML / CSS / JavaScript 实现的单人斗地主，对战两个 AI 对手。无需构建、无需服务器、无需安装任何依赖，双击 `index.html` 即可开局。

## ✨ 核心特性

- **🎯 完整经典规则** — 覆盖单张、对子、三张、三带一、三带二、顺子、连对、飞机、飞机带单/双翅膀、四带二、炸弹、王炸共 14 种牌型
- **🤖 双 AI 对手** — 基于手牌强度的叫分策略 + 最小合法出牌算法，队友领先时自动放水，合法且可理解
- **💰 完整积分体系** — 叫地主 / 抢地主翻倍、炸弹 & 王炸翻倍、春天 & 反春翻倍、地主双倍结算，累计总分跨局保留
- **💡 一键提示** — 自动枚举所有能压过上家的合法牌型，循环切换参考
- **🔊 合成音效** — 基于 Web Audio API 的出牌 / 炸弹 / 王炸 / 报警 / 结算音效，无需音频文件
- **📱 响应式布局** — 经典绿色牌桌视觉，桌面与移动端自适应
- **🧪 全量单元测试** — 自研零依赖测试框架，覆盖牌组、规则、AI、游戏状态、文件一致性

## 🚀 快速开始

### 方式一：直接打开（推荐）

```bash
# 克隆或下载本仓库后，直接用浏览器打开
index.html
```

无需 Node.js、无需 npm install、无需构建工具。

### 方式二：本地静态服务器（可选）

如果浏览器对本地文件有安全限制，可以起一个静态服务：

```bash
# Python 3
python -m http.server 8080

# 或 Node.js
npx serve .
```

然后访问 `http://localhost:8080`。

## 🎮 玩法说明

### 基本流程

1. **发牌** — 54 张牌，每人 17 张，剩余 3 张为底牌
2. **叫地主** — 从玩家开始轮流叫分，可叫地主或不叫；有人叫地主后进入抢地主环节
3. **确定地主** — 地主获得 3 张底牌，其余两家为农民
4. **出牌** — 地主先出，轮流出牌，必须出比上家更大的同类型牌，或选择不出
5. **胜负** — 任意一家出完手牌即结束，地主出完则地主胜，任一农民出完则农民胜

### 操作方式

| 操作 | 说明 |
|------|------|
| 点击手牌 | 选中 / 取消选中 |
| **出牌** | 打出已选中的牌 |
| **提示** | 自动选出一手能压过上家的牌，多次点击循环切换 |
| **不出** | 跳过本轮（首家出牌时不可用） |
| **新一局** | 保留总分，重新发牌 |

### 牌型一览

| 牌型 | 说明 | 示例 |
|------|------|------|
| 单张 | 任意一张牌 | `♠A` |
| 对子 | 两张同点数 | `♥K ♣K` |
| 三张 | 三张同点数 | `♠5 ♥5 ♣5` |
| 三带一 | 三张 + 一单 | `3×7 + ♦2` |
| 三带二 | 三张 + 一对 | `3×Q + 2×4` |
| 顺子 | ≥5 张连续单牌（不含 2 / 王） | `3 4 5 6 7` |
| 连对 | ≥3 对连续对子（不含 2 / 王） | `33 44 55` |
| 飞机 | ≥2 组连续三张（不含 2 / 王） | `3×5 3×6` |
| 飞机带单 | 飞机 + 同数量单牌 | `3×5 3×6 + 7 8` |
| 飞机带双 | 飞机 + 同数量对子 | `3×5 3×6 + 77 88` |
| 四带二单 | 四张 + 两张单牌 | `4×9 + 3 J` |
| 四带二对 | 四张 + 两对对子 | `4×9 + 33 JJ` |
| 💣 炸弹 | 四张同点数 | `4×A` |
| 🚀 王炸 | 小王 + 大王 | `SJ BJ` |

> **炸弹**可压任意非炸弹 / 非王炸牌型；**王炸**是最大牌型，可压一切。

## 🏗️ 技术架构

### 设计理念

- **零依赖** — 不引入任何第三方库，所有逻辑原生实现
- **零构建** — 源码即产物，ES Module 直接在浏览器运行
- **纯函数核心** — 牌组、规则、AI、状态机均为无副作用纯函数，便于测试
- **状态驱动渲染** — UI 只读状态渲染 DOM，不重复实现规则逻辑

### 模块分层

```
┌─────────────────────────────────────────┐
│              index.html                  │  入口 + 布局骨架
├─────────────────────────────────────────┤
│              styles.css                  │  经典绿色牌桌视觉系统
├─────────────────────────────────────────┤
│  main.js / browser-app.js  (控制器层)    │  事件绑定 + AI 调度 + 状态流转
├─────────────────────────────────────────┤
│              ui.js      (渲染层)          │  纯 DOM 渲染，只读 state
├─────────────────────────────────────────┤
│            game.js    (状态机层)          │  叫地主 / 出牌 / 结算 / 倍数
├──────────────┬──────────┬───────────────┤
│  cards.js    │ rules.js │   ai.js       │  领域逻辑层（纯函数）
│  牌组模型     │ 规则引擎  │  AI 决策      │
└──────────────┴──────────┴───────────────┘
```

### 关键技术点

- **牌型识别引擎** (`rules.js`) — 基于分组 + 连续性检测的牌型评估器，统一 `evaluatePlay` 入口返回结构化牌型对象
- **AI 候选生成** (`ai.js`) — 按点数分组后枚举顺子 / 连对 / 飞机 / 三带 / 四带二等所有合法组合，排序后取最小可压牌
- **不可变状态机** (`game.js`) — 每次操作返回新状态对象，完整克隆手牌与历史，支持时间回溯与调试
- **双入口设计** — `main.js`（ESM 模块化版本）+ `browser-app.js`（单文件合并版本），后者可直接 `file://` 打开不受 CORS 限制

## 🎨 设计亮点

### 经典绿色牌桌

采用径向渐变模拟真实牌桌绒布质感，米白色卡牌配红黑花色，金黄色操作按钮，还原线下棋牌室氛围。

### 信息密度合理

- 顶部状态栏：当前阶段提示 + 音效开关 + 新一局
- 桌面中央：底牌区 + 实时倍数/炸弹统计 + 上家出牌区
- 玩家区：手牌扇形排列 + 选中上浮动画 + 操作按钮栏
- AI 区：牌背显示 + 剩余张数 + 地主身份徽章

### 报警机制

当任意玩家剩余 1 或 2 张牌时，自动触发报警提示，提醒对手注意防守。
